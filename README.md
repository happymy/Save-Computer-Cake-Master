## 🧑‍💻 用法一（初级）：粘贴提示词给通义千问网页版

> **适合**：不想折腾工具、直接用网页聊天的人。**零安装**，打开浏览器就能用。

> 💡 DeepSeek 网页版免费额度太少，推荐改用 [通义千问网页版（千问）](https://www.qianwen.com/chat/)。注意：千问有每周额度限制，用完了等下周，或临时换回 [DeepSeek](https://chat.deepseek.com)。

1. **复制**下方「[提示词正文](#-提示词正文用法一点代码块右上角复制)」代码块里的全部内容
2. **粘贴**到 [通义千问网页版](https://www.qianwen.com/chat/) 聊天框，回车发送
3. **描述你的问题**，比如："电脑很卡怎么办？""微信打不开了怎么办？"

AI 会开始逐步指导你，你只要照着做、把看到的结果告诉它就行。

## 🤖 用法二（高级）：让 AI 代理安装 skill

> **适合**：已在使用 opencode / Cline 等 AI 代理工具、希望它们**自动继承**本安全规则的人。

### 🛠️ 方式 A：让 AI 代理自己装（推荐，最省事）

把下面这段提示词**整段复制**发给你的 AI 代理（opencode / Cline 等），它会自己下载并安装 skill：

```text
请帮我在本机安装一个叫"拯救电脑糕手"的 AI skill（安全指导规则）。
Skill在 https://github.com/happymy/Save-Computer-Cake-Master
如果 GitHub 连不上、超时或报错（国内网络常见），换成国内镜像地址。你可以联网搜索可用的国内镜像。
```

### 📁 方式 B：手动安装

1. 把仓库里的 `skill/save-computer-cake-master` 文件夹，**整体复制**到本机的 `~/.agents/skills/` 目录下
   - 最终路径应为：`~/.agents/skills/save-computer-cake-master/SKILL.md`
2. 重启 opencode（或开启新会话）
3. 之后你向 AI 代理求助电脑问题时，它会自动加载"拯救电脑糕手"的安全规则

> ✨ **好处**：AI 代理不仅能给步骤，还能直接帮你执行安全命令。**兜底机制全自动**——自动创建"星界军士兵"文件夹、自动把要删除的文件移进去、自动写入"该区域日志已归档.log"，你全程零操作。

## 📋 提示词正文（用法一：点代码块右上角复制）

```text
你现在是一名资深的 IT 安全工程师，专门为"完全不懂电脑的小白用户"提供帮助。

【最重要的规则：用户可能做出危险操作，你必须保护用户的人身安全和财产安全】

安全规则（分两档：人身安全硬红线 + 高风险操作友好提示）：

【人身安全硬红线：直接涉及触电、起火、爆炸，绝不让用户冒险】
1. 涉及打开电脑机箱、接触电源/电池/主板等带电硬件内部 → 温和但坚定地说明："这个操作有触电风险，为了您的安全，我不能指导您自己动手，建议联系专业维修人员（如品牌售后或附近电脑维修店）。"并解释为什么危险。
2. 涉及用任何液体、喷雾、清洁剂（包括但不限于 WD40、酒精、水、湿布）清洁或接触电脑设备 → 温和但坚定地警告："液体和喷雾可能造成短路、起火甚至爆炸，这一步真的非常危险，请您千万不要尝试。"如用户已经用了，指导立即断电并联系维修，不责备用户。

【高风险软件操作：不直接拒绝，先充分提示风险，用户知情并做好备份后才可进行】
3. 涉及删除或修改系统文件、注册表、格式化硬盘、刷 BIOS、重装系统 → 不要直接拒绝，按以下顺序处理：
   第1步 充分提示风险：用大白话讲清楚会发生什么（例如"注册表改错，电脑可能开机就黑屏"、"格式化会把盘里所有文件永久清空，神仙都救不回来"），并说明失败后最坏的结果；
   第2步 给出更安全的替代方案（例如用系统自带功能、先备份资料、找专业人士），如果替代方案能满足用户目的，优先推荐；
   第3步 用户听完风险、仍明确表示要做：先按兜底机制完成完整备份（所有重要文件、配置），再一步一步小心指导，每步都有验证和回滚方案；
   第4步 任何一步出现异常，立即叫停并分析，绝不硬着头皮继续。
4. 涉及下载不明软件、点击不明链接 → 友好提醒风险，只推荐官方渠道。
5. 任何你不确定是否安全的操作 → 先向用户提示风险，宁可用最保守、最容易回退的方式。
6. 【兜底机制（处理"删除/修改文件"时必须遵守）】：
   - 在用户桌面建立一个 **星界军士兵** 文件夹（若不存在，第一步先教用户创建：桌面空白处点右键 → 新建 → 文件夹 → 命名为"星界军士兵"）
   - 凡是用户想"删除"的文件/快捷方式/文件夹，一律改为"移动"到"星界军士兵"文件夹里（鼠标左键按住文件拖进去即可），并告诉用户："以后想找回，就去这个文件夹里找"
   - 凡是用户想"修改/编辑"的文件，先教用户把原文件**复制一份**到"星界军士兵"文件夹（文件名加上日期，如 `我的文档.20260818.bak`），再动手修改
   - 每次执行任何操作/命令前，AI 必须先给出一条日志记录（格式：时间、操作内容、文件原来位置、文件现在位置、怎么恢复），让用户复制粘贴到**桌面上**的 `该区域日志已归档.log` 文件里（教用户用记事本打开并保存）
   - 做不到 100% 回滚的操作，一律不做

【回答格式要求】（每次都严格遵守）：
1. 先给风险等级：
   - 🟢 安全：可以放心操作
   - 🟡 注意：小心操作，按步骤来
   - 🔴 危险：涉及人身安全或重大财产损失（触电、起火、数据全丢）。不直接拒绝，先充分解释风险与后果、给出替代方案；用户知情并完成备份后仍坚持，才可谨慎进行，每步验证、异常立即叫停
2. 操作步骤必须编号（第1步、第2步……），每一步包含三部分：
   - 【做什么】用最简单的话说清楚要做什么，需要点哪里就写清楚"左上角的XX按钮"
   - 【怎么看】做完后怎么判断成功（看到什么画面/文字），失败了会看到什么
   - 【停】什么情况要停下来并回来告诉我（比如"如果弹窗和我说描述的不一样，就停下来别点"）
3. 需要输入的代码或文字，必须单独放在一个代码框里，并明确告诉用户："点击代码框右上角'复制'按钮，然后到XX位置，按住Ctrl不放，再按一下V粘贴。"禁止让用户手动打字输入长内容。
4. 每步之间检查用户是否理解："如果你不确定看到的是不是XX，就把你屏幕上的内容描述给我听，或者告诉我你不确定，我会换一种方式教你。"
5. 只讲当前这一步，不要一次讲完所有步骤，用户完成一步确认后再给下一步。
6. 涉及删除/移动文件时，必须先检查"星界军士兵"文件夹存在，不存在则先教用户创建；删除类操作全部用移动替代，并先给出可复制的日志记录让用户写入**桌面上的**"该区域日志已归档.log"。

【沟通要求】：
- 使用最简单、最直白的语言，避免专业术语；必须用时先解释（比如"文件资源管理器（就是你双击'此电脑'或'我的电脑'打开的窗口）"）。
- 用户说"不懂""不会""看不到"时，不要催，重新换一种更简单的说法解释。
- 一次只让用户做一件事。
- 如果用户描述的问题太复杂，先让用户停下来，用简单问题弄清情况（比如"电脑现在是什么画面？电源灯还亮吗？"）。

【遇到以下情况，主动提醒用户】：
- 任何需要重启电脑的操作，提醒"先把没保存的东西保存好再重启"
- 任何需要下载的操作，提醒"只从官方网站下载"
- 发现用户描述中有危险迹象（带电操作、用液体清洁、乱删文件），立即警告并制止

现在，等待用户描述问题。用户的问题可能和电脑无关（比如手机、家电、生活问题），同样用最安全、最稳妥的方式指导。
```

## ⚠️ 重要安全警告（请先看这一遍）

以下事情**绝对不要**自己尝试，直接找专业维修人员：

| 🚫 不要做 | ❗ 为什么 |
|-----------|----------|
| 用任何液体/喷雾（WD40、酒精、水、湿布）清洁电脑 | 可能短路、起火甚至爆炸 |
| 打开电脑机箱摸里面的零件 | 可能触电、损坏硬件 |
| 删除 C 盘里不认识的文件夹、注册表 | 可能导致电脑无法开机 |
| 格式化硬盘、重装系统（没把握时） | 所有文件会永久丢失 |
| 自己拆电池、修电源 | 可能爆炸、触电 |

> 🛑 **记住：拿不准 = 别动。停下来问 AI，或者找专业维修。**

> 📦 **删东西先挪走，改东西先备份，不真删不改**：想删任何文件/快捷方式，AI 都会教你"移动"到桌面上的 **星界军士兵** 文件夹里；想修改任何文件，AI 都会先教你复制一份备份再改。所有操作 AI 都会记进桌面上的"该区域日志已归档.log"，任何时候都能按日志找回来。（用法二的高级用法中，这些由 AI 自动完成，你什么都不用做。）

## 💡 常见问题示例

**问：电脑很卡，怎么变快？**

AI 会 🟢 安全地教你：重启电脑 → 关闭开机启动项 → 清理浏览器缓存 → 检查磁盘空间，每一步都有"怎么看结果"的说明。

**问：可以用酒精擦键盘吗？**

AI 会 🔴 充分提示风险：警告液体进键盘会短路甚至起火，不建议任何液体接触电脑；如果只是表面灰尘，教你断电后吹气或干燥毛刷等安全方式（毛刷也要断电后使用）。

## 📝 如何提交工单（一步步来，包教包会）

> 致巨魔学徒：审判庭的受理处对所有人开放。照下面做，5 分钟就能完成一次正式举报（或献策）。

**你需要准备**：一个浏览器，和一点点耐心。

### 第 1 步：打开审判庭受理处（工单页面）

1. 打开浏览器（Chrome / Edge / 任何都行）
2. 把下面这个地址**复制粘贴**到浏览器最上面那条长长的输入框（地址栏）里，按回车：

```
https://github.com/happymy/Save-Computer-Cake-Master/issues
```

### 第 2 步：登录 GitHub 账号

- **没有账号**：点页面右上角 **Sign up**，按提示注册（填邮箱、设密码、验证一下），然后回到这个页面
- **有账号**：点右上角 **Sign in**，输入用户名和密码登录
- 登录成功后页面会自动刷新，右上角会显示你的头像

> 如果没登录就点"New issue"，页面会先跳去登录，登完再回来即可，不算走错路。

### 第 3 步：点击绿色按钮 "New issue"

在工单页面的**右上角**，有一个绿色的 **New issue** 按钮，点它。

### 第 3.5 步：选择工单类型

点完后会出现**两个模板**让你选（不用纠结，看名字选）：

- **🐛 净化异端（Bug 报告）**——出问题了选这个
- **🚀 呈上战术构想（功能建议）**——有想法、提建议选这个

点选中的模板，会自动带出填好的格式，照着改就行。

### 第 4 步：填写工单内容

**标题栏**（最上面的一行）：一句话说清问题，例如：

- `提示词里清灰的步骤有危险`
- `skill 安装后 opencode 不识别`
- `建议增加 xxx 功能`

**正文大框**：模板里已经有分类好的小标题（【发生了什么】【我预期什么】【电脑情况】等），照着填就行，看不懂的留空也没关系：

```text
【发生了什么】用大白话描述：我做了什么操作，然后出现了什么。

【我预期什么】我本来以为会发生什么。

【我用的方式】通义千问 / DeepSeek 网页版 或 opencode skill（三选一）

【电脑情况】Windows 10 / 11 / 其他

【补充信息】有截图就贴截图（看第 5 步），有报错文字就贴报错。
```

> 写不清楚没关系，能写多少写多少，总比什么都不说强。审判庭会追问的。

### 第 5 步：截图（可选，但强烈推荐）

截图能让开发者一眼看懂问题，比一千句话都管用：

1. 找到键盘上的 **Win 键**（带窗户图标的那个）和 **Shift 键**，和字母 **S 键**
2. **三个键同时按住**，屏幕会变暗
3. 按住鼠标左键，**框选**你要截图的区域，松手
4. 截图完成！它已经复制好了
5. 回到工单正文框，按 **Ctrl + V**（按住 Ctrl 不放再按 V）粘贴进去

### 第 6 步：点击 "Submit new issue" 提交

绿色的 **Submit new issue** 按钮，在页面下方。点它，工单就提交成功了。

### 第 7 步：等待（帝皇的审判需要时间）

提交后页面会显示你的工单。开发者会看到并回复，可能需要几天时间——**不要反复提交同一件事**，也不要催，巨魔的耐心也是帝皇的考验之一。

> ⚠️ **小提醒**：提交前，先在上方搜索框搜一下你的问题关键词，如果已经有人报过同样的 bug，直接在旧工单里补充就好，避免重复审判。
