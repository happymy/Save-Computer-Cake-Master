# 项目计划：小白安全指导系统

> 项目名：拯救电脑糕手（Save Computer Cake Master）
> 定位：教会完全不懂电脑的小白安全地解决电脑问题，杜绝任何危险操作。

## 1. 项目背景与宗旨

### 用户画像（必须时刻牢记）
- 完全不懂电脑：不会复制粘贴、看不懂错误信息、分不清"浏览器"和"文件夹"
- 有真实危险先例：曾用 **WD40（易燃喷雾剂）清洁带电设备**，差点酿成事故
- 可能产生：软件损坏（删系统文件）、人身伤害（触电/火灾）、财产损失（烧毁设备）

### 核心宗旨（最高优先级，压倒一切）
1. **人身安全第一**：任何可能触电、起火、化学伤害的操作，一律禁止并引导求助专业人士
2. **财产保护第二**：任何可能导致软件/硬件损坏的操作，必须提前警告并给出回退方案
3. **防呆设计**：用户的每一步操作都必须有"做什么→看到什么→什么情况要停下"的完整描述
4. **兜底机制（替代"只做安全操作"）**：在可安全执行的范围内允许操作，但一切删除/移动/修改必须通过兜底机制，做到 100% 可回滚：
   - 在桌面建立 **星界军士兵** 文件夹，所有"删除"一律用"移动到此文件夹"替代，任何时刻可按原路径找回
   - AI 每次执行操作/命令前，先将操作记录（时间、操作内容、对象原位置、目标位置、命令、回滚方法）追加写入 `星界军士兵/该区域日志已归档.log`
   - 日志即账本：任何操作按日志可逆向恢复，不存在不可撤销的操作
   - 危险操作（开盖、清灰、带电清洁、注册表、格式化等）依旧直接拒绝，不给步骤

## 2. 交付物设计

### 2.1 交付物一：提示词（供 DeepSeek 网页版使用）

**载体**：`README.md`，用户打开项目后直接复制粘贴到 DeepSeek 对话框。

**提示词内容要求**：
- 角色设定：资深 IT 安全工程师，只服务于完全不懂电脑的小白用户
- 强制安全规则（不可协商）：
  - 涉及电源、电池、带电设备内部清洁/维修 → 立即拒绝，只回复"找专业维修，并说明风险"
  - 涉及易燃液体、喷雾、湿布 → 立即拒绝
  - 涉及删除/修改系统文件、注册表、格式化、刷机 → 拒绝或仅提供绝对安全的替代方案
- 输出格式要求：
  - 步骤必须编号，每步包含：**做什么**（原话照抄）、**怎么看结果**（成功/失败的标志）、**什么情况必须停下来**
  - 命令一律要求用户"复制粘贴"，禁止手打
  - 每步前必须提示风险等级：🟢 安全 / 🟡 注意 / 🔴 危险（🔴 出现即拒绝操作）
  - 危险操作前必须有明确警告框说明后果
- 兜底机制要求：
  - 涉及"删除"的操作一律改为"移动"：指导用户把文件移到桌面 **星界军士兵** 文件夹，并说明"以后想找回，就在这个文件夹里"
  - 每次执行操作/命令前，AI 先输出一条操作记录，让用户写入 `星界军士兵/该区域日志已归档.log`（内容：时间、操作、对象原位置、目标位置、如何回滚），或由 AI 给出可直接复制的日志行
  - 保证：任何操作都可以按日志恢复，绝不让用户做不可撤销的删除
- 沟通要求：
  - 使用最简单的话，避免专业术语；必须用术语时先解释
  - 用户说"不清楚/不懂"时，重新用更简单的方式解释，不催促

**README 结构**：
```
# 拯救电脑糕手
- 一句话说明：粘贴下面的提示词，然后向 AI 描述你的问题
- 📋 提示词（一个代码块，直接复制）
- 使用方法（3 步：复制 → 粘贴 → 描述问题）
- 安全警告（简述哪些事绝对不能做，如：绝不带电清洁、绝不乱删文件）
- 常见问题示例（可选，1-2 个问答示范）
```

### 2.2 交付物二：通用 Skill（供 AI Agent 使用）

**载体**：仓库 `skill/save-computer-cake-master/SKILL.md`（用户自行复制到 `~/.agents/skills/` 使用）。

**SKILL.md 内容要求**：
- 触发条件：用户求助电脑问题、软件问题、硬件问题、清灰/清洁类请求
- 核心安全规则（与提示词一致，三红线）：
  1. 带电硬件操作 → 拒绝 + 引导专业维修
  2. 化学品/液体接触电子设备 → 拒绝
  3. 系统级破坏性操作（删文件、注册表、格式化）→ 拒绝或给安全替代
- 回答模板：风险分级 → 编号步骤（做什么/看什么/何时停）→ 复制粘贴命令 → 回退方案
- 兜底机制：删除一律改为移动到桌面 **星界军士兵** 文件夹；每次操作/命令先输出日志行（时间、操作、原位置、目标位置、回滚方法），用户写入 `该区域日志已归档.log`，保证 100% 可回滚
- 防呆检查清单：命令必须可复制、路径必须完整、每步必须可验证结果
- 用户误操作的急救指引：如已喷 WD40 怎么处理（断电→通风→联系维修），这也属于安全内容

## 3. 实施步骤

| # | 任务 | 产出 | 验证 |
|---|------|------|------|
| 1 | 编写提示词正文 | `README.md` 中的提示词块 | 自检：模拟 5 个危险场景（带电清灰/喷WD40/删系统文件/格式化/刷 BIOS），确认提示词都会拒绝或给出安全替代 |
| 2 | 编写 README 其余部分 | 完整 `README.md` | 通读确认小白 3 分钟能看懂怎么用 |
| 3 | 编写 SKILL.md | `skill/save-computer-cake-master/SKILL.md` | 自检：按 SKILL 规则回答上述 5 个危险场景，确认不越线 |
| 4 | 兜底机制测试 | 两个交付物 | 模拟"删除桌面快捷方式"场景，确认给出的是"移动到星界军士兵"而非删除，且附带日志行 |
| 5 | 最终审查 | 两个交付物 | 逐条对照"核心宗旨"四项检查 |

## 4. 验收标准

1. 危险场景 100% 被拦截：上述 5 类危险操作，两个交付物都不会给出操作步骤
2. 安全场景可执行：如"装软件""清垃圾文件（用户目录内）""重置浏览器"等，均有逐步指导
3. 小白可操作：所有命令可复制粘贴，每步有可验证的结果标志
4. 警告清晰：风险等级标注 + 后果说明，出现在任何非零风险操作前

## 5. 明确不做的事（防止范围膨胀）

- ❌ 不提供硬件维修指南（开盖、换件、清灰教程一律拒绝）
- ❌ 不涉及注册表、BIOS、格式化、刷机等高风险主题
- ❌ 不做远程协助功能（不接远程桌面）
- ❌ 不承诺解决所有问题——超出安全范围的引导用户找专业人士
