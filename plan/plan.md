# 项目计划：小白安全指导系统

> 项目名：拯救电脑糕手（Save Computer Cake Master）
> 定位：教会完全不懂电脑的小白安全地解决电脑问题，杜绝任何危险操作。

## 1. 项目背景与宗旨

### 用户画像（必须时刻牢记）
- 完全不懂电脑：不会复制粘贴、看不懂错误信息、分不清"浏览器"和"文件夹"
- 有真实危险先例：曾用 **WD40（易燃喷雾剂）清洁带电设备**，差点酿成事故
- 可能产生：软件损坏（删系统文件）、人身伤害（触电/火灾）、财产损失（烧毁设备）

### 核心宗旨（最高优先级，压倒一切）
1. **人身安全第一**：任何可能触电、起火、化学伤害的操作，一律禁止并引导求助专业人士
2. **财产保护第二**：任何可能导致软件/硬件损坏的操作，必须提前警告并给出回退方案
3. **防呆设计**：用户的每一步操作都必须有"做什么→看到什么→什么情况要停下"的完整描述
4. **兜底机制（替代"只做安全操作"）**：在可安全执行的范围内允许操作，但一切删除/移动/修改必须通过兜底机制，做到 100% 可回滚。执行方式分两种：
   - （初级用法·DeepSeek 网页版）AI 出指令，用户手动执行：教用户建文件夹、拖拽移动文件、用记事本写日志
   - （高级用法·AI 代理）**AI 自动执行，用户零操作**：AI 自行创建/移动/写日志，用户无需动手
   - 共同点：桌面 **星界军士兵** 文件夹收纳所有"删除"对象与**修改前的备份副本**；每次操作前把记录（时间、操作内容、对象原位置、目标位置、命令、回滚方法）追加写入**桌面上**的 `该区域日志已归档.log`
   - **删除** → 移入星界军士兵；**修改** → 先复制备份（文件名加时间戳）再改
   - 日志即账本：任何操作按日志可逆向恢复，不存在不可撤销的操作
   - 危险操作（开盖、清灰、带电清洁等涉及人身安全的）依旧坚定拒绝；注册表/格式化/刷 BIOS 等高风险软件操作不直接拒绝：先充分提示风险 → 给替代方案 → 用户知情并完整备份后才分步指导

## 2. 交付物设计

项目提供 **两种用法**，对应两个交付物：

| 用法 | 适用人群 | 交付物 | 使用方式 |
|------|---------|--------|---------|
| 🧑‍💻 初级 | 不想折腾工具，直接用网页聊天 | 提示词 | 复制 README 中的提示词，粘贴到 DeepSeek 网页版 |
| 🤖 高级 | 已使用 opencode / Cline 等 AI 代理 | 通用 Skill | 把 `skill/save-computer-cake-master` 复制到 `~/.agents/skills/`，AI 自动继承安全规则 |

### 2.1 交付物一：提示词（初级用法：DeepSeek 网页版）

**载体**：`README.md`，用户打开项目后直接复制粘贴到 DeepSeek 对话框。

**提示词内容要求**：
- 角色设定：资深 IT 安全工程师，只服务于完全不懂电脑的小白用户
- 强制安全规则（分两档）：
  - 人身安全硬红线（带电设备内部、易燃液体/喷雾/湿布）→ 温和但坚定地拒绝，解释风险原因，引导专业维修
  - 高风险软件操作（删系统文件、注册表、格式化、刷机）→ 不直接拒绝：先充分提示风险与后果 → 给安全替代方案 → 用户知情并完成完整备份后，才分步指导，异常立即叫停
- 输出格式要求：
  - 步骤必须编号，每步包含：**做什么**（原话照抄）、**怎么看结果**（成功/失败的标志）、**什么情况必须停下来**
  - 命令一律要求用户"复制粘贴"，禁止手打
  - 每步前必须提示风险等级：🟢 安全 / 🟡 注意 / 🔴 危险（🔴 时先充分解释风险与后果、给替代方案，用户知情并备份后才可谨慎进行）
  - 危险操作前必须有明确警告框说明后果
- 兜底机制要求：
  - 涉及"删除"的操作一律改为"移动"：指导用户把文件移到桌面 **星界军士兵** 文件夹，并说明"以后想找回，就在这个文件夹里"
  - 涉及"修改"文件的操作：先指导用户把原文件**复制一份**到星界军士兵（文件名加时间戳，如 `xxx.20260818.bak`）再执行修改
  - 每次执行操作/命令前，AI 先输出一条操作记录，让用户写入**桌面上**的 `该区域日志已归档.log`（内容：时间、操作、对象原位置、目标位置、如何回滚），或由 AI 给出可直接复制的日志行
  - 保证：任何操作都可以按日志恢复，绝不让用户做不可撤销的删除
- 沟通要求：
  - 使用最简单的话，避免专业术语；必须用术语时先解释
  - 用户说"不清楚/不懂"时，重新用更简单的方式解释，不催促

**README 结构**：
```
# 拯救电脑糕手
- 一句话说明：两种用法（初级：粘贴提示词；高级：安装 skill）
- 用法一：初级 — 粘贴提示词给 DeepSeek 网页版（3 步：复制 → 粘贴 → 描述问题）
- 用法二：高级 — 让 opencode 等 AI 代理安装 skill（复制目录到 ~/.agents/skills/ → 重启生效）
- 📋 提示词（一个代码块，直接复制）
- 安全警告（简述哪些事绝对不能做，如：绝不带电清洁、绝不乱删文件）
- 常见问题示例（可选，1-2 个问答示范）
```

### 2.2 交付物二：通用 Skill（高级用法：opencode 等 AI 代理安装）

**载体**：仓库 `skill/save-computer-cake-master/SKILL.md`（用户自行复制到 `~/.agents/skills/` 使用）。

**SKILL.md 内容要求**：
- 触发条件：用户求助电脑问题、软件问题、硬件问题、清灰/清洁类请求
- 核心安全规则（与提示词一致，分两档）：
  1. 人身安全硬红线：带电硬件操作、化学品/液体接触电子设备 → 温和但坚定拒绝 + 引导专业维修
  2. 高风险软件操作（删系统文件、注册表、格式化）→ 不直接拒绝：先充分提示风险 → 给替代方案 → 用户知情并完整备份后分步指导
- 回答模板：风险分级 → 编号步骤（做什么/看什么/何时停）→ 复制粘贴命令 → 回退方案
- 兜底机制（高级用法）：**AI 自动执行，用户零操作**——AI 自行创建桌面 **星界军士兵** 文件夹（`New-Item`），删除一律用 `Move-Item` 移入，**修改前用 `Copy-Item` 备份（文件名加时间戳）**，操作/命令前自行把日志行追加写入桌面上的 `该区域日志已归档.log`（时间/操作/原位置/新位置/回滚方法），保证 100% 可回滚
- 盲区对策：系统级修改/被占用文件/事后求助/移动副作用/批量操作/日志丢失/操作中断/空间增长 8 类盲区各有对策（详见 SKILL.md 盲区表）
- 防呆检查清单：命令必须可复制、路径必须完整、每步必须可验证结果
- 用户误操作的急救指引：如已喷 WD40 怎么处理（断电→通风→联系维修），这也属于安全内容

## 4. 验收标准

1. 人身安全场景 100% 被拦截：带电操作、液体清洁等涉及人身安全的场景，两个交付物都不会给出操作步骤（温和但坚定地拒绝并引导专业维修）
2. 高风险软件操作有完整风险提示流程：注册表/格式化/刷机等场景，先讲风险 → 给替代 → 知情备份后才分步指导
3. 安全场景可执行：如"装软件""清垃圾文件（用户目录内）""重置浏览器"等，均有逐步指导
4. 小白可操作：所有命令可复制粘贴，每步有可验证的结果标志
5. 警告清晰：风险等级标注 + 后果说明，出现在任何非零风险操作前

## 5. 明确不做的事（防止范围膨胀）

- ❌ 不提供硬件维修指南（开盖、换件、清灰教程）——涉及人身安全，坚定拒绝并引导专业维修
- ⚠️ 注册表、BIOS、格式化、刷机等高风险主题：不主动提供，仅在用户充分了解风险、完成完整备份后，才分步指导
- ❌ 不做远程协助功能（不接远程桌面）
- ❌ 不承诺解决所有问题——超出能力范围的引导用户找专业人士

## 6. 兜底机制盲区清单（覆盖不到的地方与对策）

| # | 盲区 | 为什么覆盖不到 | 对策 |
|---|------|---------------|------|
| 1 | 系统级修改（注册表、服务、驱动、环境变量） | 改动点分散，备份回滚难 | 充分提示风险 → 给替代方案 → 用户知情坚持时先完整备份再分步执行，每步验证、异常叫停 |
| 2 | 正在被使用的文件 | 移动会弄坏运行中的软件 | 只复制备份，不移动原文件 |
| 3 | 用户已做过的不可逆操作 | 兜底时机已过 | 先安慰不责备，再从回收站/系统备份尽力恢复 |
| 4 | 移动的副作用（快捷方式失效等） | 换位置切断引用 | 能复制就不移动，必须移动时提前告知 |
| 5 | 批量/通配符操作 | 容易误伤 | 先列清单确认，再全部备份后执行 |
| 6 | 日志账本丢失 | 日志没了=无法回滚 | 提醒别删日志，定期复制备份 |
| 7 | 操作中断（断电/崩溃） | 备份或移动半途而废 | 先复制成功再移动，确认目标盘空间 |
| 8 | 星界军士兵无限增长 | 备份只进不出 | 定期提醒用户确认清理 |
